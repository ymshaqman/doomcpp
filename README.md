# doomcpp
DOOM clone with 1 level programmed in C++. The purpose of this project was to learn and familiarize myself with the C++ language and its different libraries for the intention of applying for game development jobs.

Libraries used:
  1. SDL

AI Disclaimer:
AI was used in this project to:
  1. Understand the intricacies of the C++ language (ex. Classes and object implementations)
  2. Syntax help with C++
  3. Importing and installing the SDL library
  4. Provide a general framework as to the different components of a game in C++ (main, game, renderer, etc,.)
